# RGX | AQoL — Another Quality of Life

Quality-of-life automation for **WoW Forever** and **Classic Era**, built on RGX-Framework.

## Features

- **Questing** — automate quest accept and turn-in, with an optional override key, and automate gossip.
- **Automation** — accept summons and resurrections, release in PvP with a configurable delay.
- **Vendors** — sell junk and repair gear automatically, with optional chat summaries.
- **Options panel** — `/qol` opens a themed options panel; the minimap button toggles it.

## Requirements

- [RGX-Framework](https://www.curseforge.com/wow/addons/rgx-framework) (required)
- ElvUI (optional)

## Commands

- `/qol` — open the options panel
- `/rl` — reload the UI
